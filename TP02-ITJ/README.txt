Para ejecutar el código se necesita tener instaladas las siguientes bibliotecas:

- NumPy

- pandas

- Matplotlib

- scikit-learn

Intrucciones para ejecutar el código:
Se recomienda ejecutar las celdas en orden.
Deberás completar la variable "carpeta" con la ruta donde tengas los archivos.
Tener en cuenta que el código está pensado para ser ejecutado en Spyder, por lo que puede suceder que algún gráfico no se vea si estás en otro entorno.
En ese caso añadir plt.show() al final del código del gráfico.
Al final del archivo se guarda un documento csv. Este tiene como separador ";". En caso de querer otro simplemente cambiar el parámetro sep.
